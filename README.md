# Sähkön kulutuksen ja tuotannon tasapaino Suomessa

Tämä opinnäytetyö analysoi Suomen sähkön tuotannon ja kulutuksen tasapainoa Fingridin avoimen datan avulla.
Analyysin keskiössä on nettokuorma, joka kuvaa kulutuksen ja kotimaisen tuotannon välistä erotusta ja siten sähkön tuonti- tai vientitarvetta.
Aineisto perustuu alun perin kolmen minuutin välein mitattuun dataan, joka on esikäsitelty ja aggregoitu analyysin tarkoituksen mukaan.
Pitkän aikavälin kehitystä tarkastellaan liukuvien keskiarvojen avulla, kun taas jakaumaa ja vaihtelua analysoidaan tuntikeskiarvoihin perustuvilla boxplot-kuvaajilla.
Visualisointien avulla tunnistetaan vuosi-, kausi- ja vuorokausivaihtelua sähköjärjestelmässä.
Projektin tavoitteena on tuottaa selkeä ja datalähtöinen kuva Suomen sähköjärjestelmän tasapainosta sekä luoda pohja jatkoanalyysille, kuten klusteroinnille.
